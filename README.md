# Albino & Bayao — Advocacia

Site institucional do escritório Albino & Bayao, com direção editorial contemporânea, navegação responsiva e contato direto via WhatsApp.

## Publicação

O site é uma página estática e pode ser publicado diretamente pelo GitHub Pages.

## Estrutura

- `index.html`: conteúdo semântico da página
- `styles.css`: sistema visual, grid responsivo e animações
- `script.js`: menu mobile e envio da mensagem pelo WhatsApp
- `assets/`: fotografias da equipe
